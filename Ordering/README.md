# Manufacturing Archives

This directory preserves fabrication packages sent for earlier board runs:

- `revA_06172026/Gerber/3210_LTE_revA_gerber.zip`
- `revB1_07202026/Gerber/Sisu_SSE-9.zip`
- `revB2_07232026/Gerber/Sisu_SSE-9.zip`

These ZIP files are historical, as-fabricated records. They are not the
preferred source for another order. The root KiCad project contains later
post-assembly corrections, and Rev B2 has known faults documented in
[`../ERRATA.md`](../ERRATA.md).

The Rev B2 BOM retained here matches the ordering snapshot. Use the root BOM
for the current engineering source and regenerate all manufacturing outputs
before fabrication.
